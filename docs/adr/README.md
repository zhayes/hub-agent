## 约定

- 一个 ADR 只记录一个决策。**结论先行**，其次是被否方案与否决原因。
- 已接受的 ADR 不做静默改写；需要变更时新增一节"复审 / 变更"，保留原结论。
- 每个 ADR 末尾写"复审触发条件"，避免决策在无人察觉的情况下过期。
- 涉及安全底线的 ADR（如 0002）必须附可执行的验证方式，不接受只有文字论证。
